# Aegis User Experience Flows

## 1. Core Sections (Three Primary Views)
1. **CHATS:**
   - Conversation list with unread badges, pinned chats, muted icons, disappearing timer indicators, online status (if enabled), and search within local chat titles.
   - Active Chat screen with E2EE status badge, safety number verification, disappearing message timer indicator, message bubble list, reaction tray, image viewer, and composer.
2. **SEARCH:**
   - Username discovery tab for finding public accounts.
   - Private account lookup via exact username or QR code scanner.
   - My QR code display modal for instant in-person identity verification.
3. **PROFILE:**
   - User profile info (Full Name, Permanent Username, Bio, Avatar, Account Type).
   - Security Key display (masked by default, click to unmask with password modal).
   - Security & Privacy settings (Read Receipts, Typing Indicators, Online Status, Disappearing Message Default, Active Devices, Blocked Users, Logout).

## 2. Design System Rules
- Dark and light theme support with automatic system preference detection.
- High-contrast typography and clear visual hierarchy.
- Subtle status badges (e.g. green indicator for verified E2EE identity, lock icon for encrypted payload).
- Mobile responsive layout with swipe gestures for conversation actions.
